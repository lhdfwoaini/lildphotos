# LilD Photos｜街上见

LilD 的个人摄影作品集，记录广州街头、家乡、建筑、风光与旅途中的日常观察。

正式网站：

https://lhdfwoaini.github.io/lildphotos/

## 网站内容

- 个人介绍与摄影自画像
- 按专题整理的摄影栏目
- 单幅作品标题、地点、摘要与完整记录
- 桌面端、平板端和手机端响应式布局
- 键盘操作、触控滑动与作品弹窗

## 文件结构

- `index.html`：页面结构、样式、栏目数据与交互
- `photos/`：网站使用的摄影作品和首页缩略图
- `favicon.svg`：网站图标
- `share-cover.jpg`：社交平台分享预览图
- `404.html`：GitHub Pages 错误页面
- `.nojekyll`：关闭 Jekyll 处理
- `robots.txt`：搜索引擎抓取规则

网站使用原生 HTML、CSS 和 JavaScript，不依赖构建工具、外部框架、CDN或网络图片。
